# Agriculture 95 — version 2.0

Cette version remplace intégralement les versions précédentes.

## Fonctionnement vérifié dans les fichiers

- cadrage initial calculé sur le Val-d’Oise ;
- clic sur n’importe quel point de la carte, à toute échelle ;
- interrogation ponctuelle du RPG via API Carto ;
- identification de la commune via l’API Géographique ;
- chargement des parcelles visibles à partir du zoom 12 ;
- clic direct sur une parcelle affichée ;
- recherche de commune ;
- activation des communes, du RPG et de l’orthophotographie ;
- panneau latéral droit fermable ;
- adaptation mobile.

## Publication

Déposer le contenu du dossier directement à la racine du dépôt GitHub Pages.
Après publication, effectuer Ctrl + F5 afin d’écarter les anciens fichiers conservés en cache.
