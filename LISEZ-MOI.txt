ATLAS DU VAL-D'OISE — PAGE AGRICULTURE

Ce dossier contient une version autonome de la page Agriculture.

Lancement local :
1. Installer Node.js 20 ou plus récent.
2. Ouvrir un terminal dans ce dossier.
3. Exécuter : npm install
4. Exécuter : npm run dev
5. Ouvrir l’adresse indiquée dans le terminal.

La page d’accueil redirige automatiquement vers /agriculture.

Contenu principal :
- app/agriculture/page.tsx : carte, filtres, légende et datavisualisation
- app/components/ToolHeader.tsx : en-tête
- app/globals.css : styles
- public/data/cartobio-val-doise.geojson : parcelles certifiées bio
- public/fonts : polices locales
- public/prefet-val-doise-logo.png : logo

Le fond de carte et certaines informations géographiques nécessitent une connexion Internet.
